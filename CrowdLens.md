# CLAUDE.md — CrowdLens Project Guide

## What is CrowdLens?

CrowdLens is a **Letterboxd-style** sentiment-powered review platform for movies, anime, and TV shows. The unique feature is the **SentiScore** (0-100) — generated by scraping Reddit/Twitter posts about a title and running VADER sentiment analysis on them. Think "Rotten Tomatoes meets real-time social media pulse."

**Live URLs during development:**
- Backend API: http://127.0.0.1:8000/api/v1/
- Frontend: http://localhost:3000
- Admin: http://127.0.0.1:8000/admin/

## Tech Stack

### Backend (COMPLETE ✅)
- **Framework:** Django 5.1 + Django REST Framework
- **Auth:** django-allauth (JWT + Google/GitHub OAuth) + dj-rest-auth + simplejwt
- **Database:** SQLite (dev) / PostgreSQL (prod) — use `SQLITE=1` prefix for all manage.py commands
- **Task Queue:** Celery + Redis + django-celery-beat
- **Sentiment:** VADER (vaderSentiment) — rule-based, no sarcasm detection
- **Scraping:** PRAW (Reddit API)
- **External APIs:** TMDB (movies/TV metadata), AniList (anime — not yet implemented)
- **Environment:** python-dotenv loads `.env` file in settings.py

### Frontend (IN PROGRESS 🚧)
- **Framework:** React 18 + Vite
- **Routing:** react-router-dom v6
- **Styling:** Tailwind CSS v4 (via @tailwindcss/vite plugin)
- **HTTP Client:** axios with JWT interceptors
- **State:** React Context for auth, useState/useEffect for data
- **Data Fetching:** @tanstack/react-query (installed but not yet wired up)

| GET | `/genres/` | All genres (no pagination) |

| Method | Endpoint | Auth | Description |

## Key Data Models

### Title (single table for movie/tv/anime)
- `title_type`: "movie" | "tv" | "anime" — discriminator field
- `senti_score`: 0-100 CrowdLens sentiment score (nullable until computed)
- `senti_positive_pct`, `senti_negative_pct`: breakdown percentages
- `senti_total_mentions`: how many social posts were analyzed
- `avg_user_rating`: average of user reviews (0.5-5.0 scale, half-star increments)
- `tmdb_rating`, `imdb_rating`: external scores
- `poster_full_url` (property): returns full TMDB image URL
- `slug`: URL-friendly identifier (e.g., "inception-2010")

### Review
- One review per user per title (unique constraint)
- `rating`: 0.5 to 5.0 in 0.5 increments (auto-rounded in save())
- `contains_spoilers`: boolean flag for frontend to hide text

### SentimentMention
- One scraped social media post
- `is_processed`: False until VADER analyzes it
- `sentiment_score`: -1.0 to +1.0 (VADER compound)
- `upvotes`, `reply_count`: engagement metrics used for weighting

### SentiScore Formula
```
weighted_avg = sum(compound_score * engagement_weight) / total_weight
base_score = ((weighted_avg + 1) / 2) * 100    # normalize to 0-100
confidence = min(total_mentions / 50, 1.0)       # builds up to 50 mentions
final_score = (base_score * confidence) + (50 * (1 - confidence))
```
- Minimum 3 mentions required
- Low mention count pulls score toward 50 (uncertain)
- High-engagement posts (upvotes/replies) weigh more

## Important Implementation Notes

1. **Always use `SQLITE=1` prefix** for any `python manage.py` commands in dev
2. **Frontend proxy is configured** — Vite proxies `/api` requests to Django at :8000, so use relative paths in axios
3. **JWT auth flow** — tokens stored in localStorage. `api/client.js` auto-attaches Bearer token and handles refresh
4. **Tailwind v4** — uses `@tailwindcss/vite` plugin, NOT the old PostCSS method. Import is `@import "tailwindcss"` in index.css. Use only core utility classes
5. **Settings loads .env** via `python-dotenv` — the `load_dotenv()` call is at top of settings.py
6. **Browse page uses URL params** — `type` comes from route path (`/movies`, `/tv`, `/anime`), mapped to API's `title_type` param
7. **Title slugs are URL identifiers** — e.g., `/title/inception-2010` maps to `Title.slug`
8. **Database has ~159 titles** loaded from TMDB (movies + TV shows)
9. **No anime data yet** — AniList sync not implemented, only TMDB
10. **SentiScores are all null** — no Reddit scraping done yet, sentiment features will show empty states
11. **The owner is a beginner** — keep code simple, well-commented, and avoid over-abstraction
